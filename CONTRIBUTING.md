# Contributing / Mathematical Defect Reports

This repository is intended for mathematical inspection and reproducible defect reporting.

If you identify a problem, please report the **earliest exact failing step** where possible:

- an incorrect identity;
- a sign or chain-rule error;
- an invalid symmetry implication;
- a hidden filter-time / physical-time conflation;
- an incorrect Sturm or enclosure step;
- a hypothesis mismatch;
- an overclaim in the theorem boundary;
- or prior art containing essentially the same theorem.

Please include enough detail to reproduce the objection.

General assessments such as “this seems wrong” are less useful than a minimal explicit countercalculation or exact citation.

No contribution or issue report is treated as endorsement, peer review, or certification unless explicitly stated.
